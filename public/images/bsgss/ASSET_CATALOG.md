# BSGSS media catalogue

All files in this directory were downloaded from the public media library of `bisnoulisansthan.in`. Files retain their WordPress media ID as a prefix, followed by a readable source name.

| Folder | Contents |
| --- | --- |
| `banners` | Homepage, campaign, and web-banner imagery |
| `branding` | BSGSS logos, marks, and identity graphics |
| `donations` | Bank, UPI, and donation-support images |
| `education` | Classroom and education-programme photos |
| `healthcare-camps` | Medical camp photographs |
| `gallery-community` | Community activities and WhatsApp event photos |
| `gallery-events` | Numbered event-gallery photographs |
| `gallery-jac` | JAC project/activity gallery photographs |
| `gallery-training` | Tailoring and skills-training photographs |
| `people` | Team and testimonial photos |
| `products` | SHG/product related media |
| `programmes-and-partners` | Programme, monitoring, and partner assets |
| `stock-images` | Source-site stock imagery |
| `legacy-page-assets` | Older page-specific images retained from the source |
| `other-source-assets` | Remaining source assets that did not fit a specific programme category |

Do not remove the numeric file prefix: it preserves traceability back to the source media library.

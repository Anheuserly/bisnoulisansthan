# BSGSS documentation

This folder describes the content-management foundation for the BSGSS website.

- [Admin content model](ADMIN_CONTENT_MODEL.md): what administrators should manage.
- [Database schema](DATABASE_SCHEMA.md): tables, important fields and relationships.
- [Content workflow](CONTENT_WORKFLOW.md): draft, review, publish and archive process.
- [Operations](OPERATIONS.md): safe setup, media and access-control guidance.
- [Public content registry](CONTENT_REGISTRY.md): one place for shared public copy, links and media references.
- [UI/UX improvement audit](UI_UX_IMPROVEMENT_AUDIT.md): page-by-page design refinements that preserve the existing public-site concept and visitor flows.
- [Complete website audit](COMPLETE_WEBSITE_AUDIT.md): prioritised findings across public routes, operations, security, accessibility, performance and search visibility.

The public website should only display records with `status = 'published'` (and public documents/media with their public flag enabled).
- [Donation acknowledgement certificates](DONATION_CERTIFICATES.md): verification and certificate issuance workflow.

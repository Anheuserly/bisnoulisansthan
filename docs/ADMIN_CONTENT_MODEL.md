# Admin content model

## What the BSGSS Control Centre should manage

| Module | Primary users | Core actions |
| --- | --- | --- |
| Pages | Editors, admins | Edit About, Our Work, Impact and contact content; save drafts; publish after review. |
| Programmes | Editors, admins | Create programme cards, assign a theme, locations, cover media and publication status. |
| Gallery & media | Editors | Upload media, add accurate alt text/captions, group images into activity albums and choose a cover image. |
| SHG products | Editors, admins | Add product name, image, description, product category, enquiry subject and featured status. Do not add prices unless approved. |
| Partner profiles | Admins | Maintain logo, public narrative, focus areas, locations and linked source document. |
| Documents | Admins | Upload/register compliance documents, reports and partner records; set public/private visibility. |
| Impact metrics | Admins | Enter a figure, reporting period and source document before showing it publicly. |
| Navigation & site settings | Super admins | Control menu visibility/order, contact details, donation CTA and social links. |
| Inquiries | Editors, admins | Assign, track and close contact messages. |
| Users & audit | Super admins | Create users, set roles, deactivate access and review important changes. |

## Recommended roles

- `super_admin`: users, roles, navigation, settings, publish/archival, documents and all content.
- `admin`: publish content, manage documents, partners, impact metrics and inquiries; cannot manage super admins.
- `editor`: create/edit drafts, upload media and submit content for review; cannot publish or alter access/settings.

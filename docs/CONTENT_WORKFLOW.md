# Content workflow

1. An editor creates a **draft** and adds complete copy, media alt text and a source where a statistic or claim is used.
2. The editor submits it as **review**.
3. An admin checks factual accuracy, spelling, accessibility, image permission, links and source document.
4. An admin publishes it by setting **published** and `published_at`.
5. Replace out-of-date information by creating a revised draft; use **archived** rather than deleting public records when history matters.

## Required checks before publishing

- A title, summary and clean URL slug are present.
- Images have useful alt text; decorative images use an empty alt value.
- Partner claims and impact figures are linked to a public source document.
- Documents intended for the public have `is_public = true` and no personal/sensitive information.
- SHG product listings have a clear enquiry route; prices, stock and payment details need explicit business approval.

## Public content status

| Status | Visible on website | Meaning |
| --- | --- | --- |
| Draft | No | Work in progress. |
| Review | No | Awaiting approval. |
| Published | Yes | Approved public content. |
| Archived | No | Preserved internal record. |

CSS Implementation Guide

Notice how this implementation avoids internal corner overlays. The glow lives strictly outside and beneath the card container: 

/* 1. Neon Card Container */
.neon-spec-card {
  background-color: #ffffff;
  border-radius: 20px;
  padding: 14px;
  border: 2px solid var(--neon-color, #ffaa00);
  
  /* Outer glow radiating around perimeter and blooming below */
  box-shadow:
    0 0 0 1px rgba(var(--neon-rgb), 0.5),
    0 8px 24px -4px rgba(var(--neon-rgb), 0.55),
    0 18px 36px -8px rgba(var(--neon-rgb), 0.25);
  transition: transform 280ms ease, box-shadow 280ms ease;
}

/* 2. Interactive Hover: Smooth Lift + Lower Atmospheric Flare */
.neon-spec-card:hover {
  transform: translateY(-5px);
  box-shadow:
    0 0 0 1.5px rgba(var(--neon-rgb), 0.8),
    0 14px 32px -2px rgba(var(--neon-rgb), 0.72),
    0 24px 48px -10px rgba(var(--neon-rgb), 0.38);
}

/* 3. Media at Top */
.card-media {
  width: 100%;
  aspect-ratio: 16 / 10;
  border-radius: 14px;
  overflow: hidden;
}

/* 4. Text Below Media */
.card-title {
  padding: 1rem 0.5rem 0.5rem;
  text-align: center;
  font-weight: 600;
}
